# setTransfers.js (модуль сохранения/обновления лидов за день)

1) собрать лиды за весь день из SKOROZVON [getLeadsToOneDay()]
2) взять все звонки из RESIDENCE [findAllCallsInResidence()]
3) в цикле масива лидов взять для каждого лида инфу о ЛД попытка трансфера и время звонка [getLeadTimeline()]
4) получить лиды из RESIDENCE и присвоить для лида кто его брокер [getLeadsOnePhone()]
5) получить всяе аудиозаписи лида из SKOROZVON [getLeadAudioUrls()]
6) получить полный обхект ЛД по его имени в лиде [getUserIdByName()]
7) получить сделан ли лид самим холдорубом или бркоером [defaineSelfLead()]
8) узнать лид уникальный или был повтор уже в базе [getInfoLeadIsUnique()]
9) елси не найден бркоер для лида от ЛД из ЗАРПЛАТНАЯ=>ЛИДЫ то искать через ЗАРПЛАТНАЯ=>ЗВОНКИ [foundCallByLeadPhone()]
10) полученым внутри цикла перебора лидов сформировать полный обхект лида и сохранить/обновить в БД [upsertNewLeadsData()]

экспортирутеся эта функция в виде крона [setTransfersCrone] или в виде скрипта [setTransfersToDB]

# setUsersStats.js (модуль созранения/обновления статистики юзера для зарплатной за день)

1) получить масив {ЛД, countCalls} из SKOROZVON [getSkorozvonCalls()]
2) получить лиды (статусы price.offer broker) из RESIDENCE [getLeadsToDate()]
3) сагрегировать все лиды по ЛД из RESIDENCE и SKOROZVON [aggregateUsersLeads()]
4) внутри масива с ЛД перебрать каждого ЛД и сформировать обхект по даным из RESIDENCE и ZKOROZVON
5) получать внутри масива перебора ЛД его полный обхект [getUserIdByName()]
6) расчитать зарплату за день ЛД / холдоруба [calculateSalaryLeadorub()] / [calculateSalaryHoldorub()]
7) расчитать чистую за день каждого ЛД [calculateClearByUser()]
8) сохранит/обновить даные ЛД статистики за день в БД [upserUsersStatsToDB()]

экспортируется эта функция в виде крона [setUsersStatsCrone()] или в виде скрипта [setUsersStatsToDB()]

# leadsRoute.js (API модуль ЛИДЫ)
1) [/api/leads/get] = получить все лиды с фильтрами
2) [/api/leads/upsert] = обновить все переданые лиды из ОКК
3) [/api/leads/offers/edit] = обновить инфу по офферам/холдам определеного лида из вкладки лиды
4) [/api/leads/edit] = обновить один лид из ОКК или из вкладки лиды
5) [/api/leads/delete] = удалить лид по его ObjectId
6) [/api/leads/create] = создать лид вручную (если не спарсился из skorozvon)
7) [/api/leads/intensity] = получить статистику лидов для ЛД за неделю
8) [/api/test/diffinity'] = получить масив {ЛД countCalls} из личного кабинета самого ЛД


# residenceRoute.js (API модуль для интерграции с RESIDENCE)
1) [/api/residence/brokersList] = получить маисв брокеров из RESIDENCE


# skorozvonRoute.js (API модуль для интеграции с SKOROZVON)
1) [/api/skorozvon/allTransfers] = получить все трансферы из SKORZVON (успешные и обрывные)


# transfersRoute.js (API модуль для трансферов)
1) [/api/transfers/create] = создать ручной лид самим ЛД [не_используется!!!]
2) [/api/transfers/get] = получить список ручных лидов от самих ЛД за диапазолн [не_исопльзуется!!!]


# usersRoute.js (API модуль дял ЮЗЕРОВ ЛД)
1) [/api/users/auth] = модуль авторизации в лидорубскую
2) [/api/users/create] = создать нового юзера
3) [/api/users/getList] = получить всех юзеров
4) [/api/users/delete] = удалить опреедлного юзера
5) [/api/users/edit] = редактировать определеного юзера


# usersStatsRoute.js (API модуль СТАТИСТИКА ЗАРПЛАТНОЙ)
1) [/api/salary/updateInfo] = вручную обновить статистику зарплатной за определнный день
2) [/api/salary/bestLidorub] = получить маисв лучших лидорубов за диапазон времени
3) [/api/salary/get] = получить даные для зарплатной




# ПРОБЛЕМЫ КОТОРЫЕ МОГУТ БЫТЬ В SERVER

1) если слетела ЗП за лид то переобновить даные по лидам за день в котором был этот лид и после этого переобновить зарплтную статистику за этот же день
можно либо вручную сделать в домашней вкладке для админа либо из кода вызвать функцию и передать gte, lte нужного дня

2) если дублируются даные по зарплатной либо сверить по кол-ву записей в БД с списком юзеров в вкладке зарпалтная и поискать различие в числе и вручную удалить повторный оюекте в mongoDB

3) слетают изменения параметров лиды изза крона тогда изменить эти параметры ночью следующего дня (когда крон перестанет обновлять даные за этот день)
